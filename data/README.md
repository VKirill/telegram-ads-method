# Архив базы TGPages

929 981 канал. Внутри: channels.sqlite с поисковыми индексами и channels-enriched.csv с полными данными выгрузки. Все части меньше 100 000 000 байт.

Скачайте все файлы .7z.001, .7z.002 и далее в одну папку. Откройте первую часть в 7-Zip либо выполните:

```sh
7zz x tgpages-2026-09-14.7z.001
```

Части являются единым архивом: для распаковки нужны все. SHA256SUMS содержит контрольные суммы частей. manifest.json содержит размеры и SHA-256 исходных файлов. При проверке оба файла извлечены потоком, их SHA-256 совпали с исходными.
