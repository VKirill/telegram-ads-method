## Что умеет скилл

| Задача | Что получит агент |
|---|---|
| Подготовить запуск | Проверку связки «аудитория → обещание → посадочная → действие» и аналитики |
| Отобрать каналы | Критерии релевантности, поиск для узких ниш и реестр с причинами выбора |
| Разобраться с пересечениями | Различие аудиторий Users и мест показа Channels; последствия исключений |
| Провести тест | Сначала креативы на фиксированном пуле, затем отдельные объявления на каналы |
| Найти идеи креативов | Нативные скриншоты, записки, мемы, демонстрации и варианты посылов |
| Получать заявки | Выбор прямого предложения, канала, бота и лид-магнита; оценку качества лидов |
| Управлять расходом | Расчёты бюджета, критерии остановки, диагностику и правила оптимизации |
| Работать в кабинете | Автоматический выбор Assistant в Chrome или Computer Use |

**Скилл самодостаточен.** Посты и видео не нужны для исполнения: правила изложены внутри пакета. [Библиография](references/sources.md) оставлена для атрибуции и дополнительного изучения.

## Быстрый старт

### Установка

Склонируй репозиторий в каталог навыков своего агента. Например, для Codex:

```bash
git clone https://github.com/VKirill/telegram-ads-method.git ~/.codex/skills/telegram-ads
```

Для BB используй каталог `~/.bb/skills/telegram-ads`, для Claude Code — `~/.claude/skills/telegram-ads`. Если каталог уже существует, сначала проверь его происхождение и локальные изменения. Подключи навык штатным способом своего клиента; при необходимости начни новую сессию.

Можно скачать ZIP репозитория и поместить распакованную папку в каталог навыков. Сохраняй структуру: рядом с `SKILL.md` должны находиться `references/` и `assets/`.

### Первое поручение

> Примени telegram-ads-method. Подготовь план рекламы для [продукт]. Аудитория — [кто и с какой задачей], география — [страны], бюджет — [сумма и валюта], цель — [действие], посадочная — [ссылка]. Начни с готовности посадочной, гипотез каналов и креативов. Укажи условия теста и критерии решения.

Для узкой задачи:

> Предложи креативные гипотезы для [продукт и сегмент]. Для каждой укажи посыл, визуал, посадочную, почему стоит проверить и по какой метрике выбирать победителя.

## Как устроен процесс

**Посадочная и измерение → гипотезы → каналы → креативы → тесты → качество заявок → оптимизация.**

Агент выбирает только необходимые этапы. Для плана по предоставленным данным браузер не нужен. При обращении к кабинету агент проверяет наличие Telegram Ads Assistant в нужном Chrome-профиле. Доступное приложение используется для поддерживаемых операций; при его отсутствии или недоступности — Computer Use. Для фактического исполнения нужны соответствующие инструменты и доступ к кабинету: сам Markdown их не устанавливает.

## Принципы работы

- **Клики и заявки — разные результаты.** Победителя оцениваем по целевому действию и его качеству.
- **Приёмы — гипотезы.** Мем или нативный баннер может сработать; гарантированного формата нет.
- **Один канал в объявлении не устраняет пересечения.** Взаимные исключения могут убрать целевых людей из всех групп.
- **Бюджет ограничен заранее.** Учебные суммы и размеры пулов не являются обязательными нормами.
- **Возможности определяет конкретный кабинет.** Валюта сама по себе не доказывает доступность сайта или географии.
- **План не равен запуску.** Создание и активация выполняются в пределах поручения и разрешённого бюджета.

## Подбор каналов из базы

[Инструкция](references/catalog.md) связывает продукт и анализ ЦА с поиском прямых и смежных площадок. [catalog.py](scripts/catalog.py) ищет каналы в локальной SQLite и соседей по карте TGPages. Путь задаётся через --db, TELEGRAM_ADS_CATALOG или локальную настройку; данные рекламы каждого проекта хранятся отдельно.

## Скачать базу

Каталог TGPages: 929 981 канал, снимок 14 сентября 2026. [Архив из четырёх частей](data/README.md), SQLite и CSV. Это данные источника, не гарантия актуальности площадки или доступности Telegram Ads.

## Методичный отбор всего пула

[Процесс](references/channel-selection.md): матрица поиска → полный реестр → сбор постов → оценка каждого канала → проверка покрытия → полный список и отдельный стартовый пул. [JSON-контракт](assets/channel-review-contract.md), [валидатор](scripts/validate_reviews.py).

Одна методика, два профиля: [Codex / Luna high](profiles/codex.md) и [Claude Code / Haiku](profiles/claude-code.md). Профили содержат только различия запуска; изменения методики автоматически общие для обоих. Доступность модели и Fast/priority проверяется в конкретной среде.

## Поиск слов в разных падежах

Установить зависимости: `python3 scripts/setup_catalog.py`. Поиск по умолчанию расширяет русские слова через pymorphy3: «Испания» → «Испании», «Испанией», «Испанию». Режим без расширения: --exact; показать формы: --explain-query. База остаётся прежней.
